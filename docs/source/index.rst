Aether documentation
====================

Aether is a personal digital environment built with Django. This documentation
covers the technical foundation, development workflow, architecture, security,
and the confirmed direction for deployment and external integrations.

The repository ``README.md`` is the concise entry point and quick-start guide.
The pages here provide the detailed explanations and reference material needed
to develop, operate, and extend the project.
